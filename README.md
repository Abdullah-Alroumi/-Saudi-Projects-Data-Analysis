# 🇸🇦 Saudi Projects Data Analysis

Analysis of 40 Saudi projects using **MySQL** and **Power BI**.

## 📊 Dashboard
- **KPIs**: 40 Projects | 18.99M SAR Budget | 5 Regions
- **Map**: Project distribution across Saudi Arabia
- **Timeline**: Activity trends (Jan 2022 – May 2023)
- **Charts**: Category & regional breakdown
- **Table**: Top project managers

## 🛠️ Tools
MySQL | Power BI | CSV

## 📌 Data Source
[Kaggle - Saudi Arabia Project Data](https://www.kaggle.com/datasets/mohamedramadan2040/saudi-arabia-project-data)
