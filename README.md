# 🇸🇦 Saudi Projects Data Analysis

Analysis of 40 Saudi projects using **MySQL** and **Power BI**.

## 📝 About

This project covers real project data from various regions across Saudi Arabia, including project names, locations, dates, and contact persons. The goal is to extract meaningful insights about project distribution, category classification, budget estimation, and personnel performance.

The data is imported from a raw CSV file into MySQL, where it is cleaned and enriched with additional fields such as region classification, project category, and estimated budget — all derived automatically using SQL logic. The final result is a clean, structured database ready for visualization in Power BI.

### Key Insights
- **Central region** leads in project count, driven by Riyadh
- **Infrastructure** is the largest category (~52% of projects)
- **April** is consistently the most active month
- **Mr. Joyee Gonzales** is the top performer with 7 projects managed
- Project activity spans 16 months (Jan 2022 – May 2023)
